# 대림대학교 AI 챗봇 (프로토타입)

Next.js + Vercel AI SDK + **Gemini API(무료)** 로 만든 학사 안내 챗봇입니다.
5가지 핵심 기능(장학, 등록, 수강신청, 성적, 교내 연락처)을 아래 세 가지 방식으로 함께 제공합니다.

1. **버튼/카드 메뉴** — 고려대 'KUChat'처럼 버튼을 눌러 화면을 이동하며 정보를 보고, 학교 공식 페이지로 바로가기 링크를 누를 수 있는 방식.
2. **키워드 FAQ** — 예를 들어 "수강"이라고 입력하면 "수강신청 기간이 언제인가요?", "재수강은 어떻게 신청하나요?" 등 관련된 미리 작성된 질문 목록이 뜨고, 그중 하나를 선택하면 정해진 답변이 나오는 방식. (KUChat이 "수강"을 검색하면 관련 안내 목록을 보여주는 것과 동일한 방식)
3. **학사 무관 질문 완전 차단** — 팀 논의 결과, 날씨/스포츠/잡담 등 학사와 무관한 질문은
   전부 예외 없이 차단하기로 했습니다. 위 키워드 FAQ에도 안 걸리고 학사 관련 키워드
   (`lib/scope.ts`)도 전혀 없는 입력이면 Gemini를 아예 호출하지 않고 고정 문구만
   보여줍니다. (예: "오늘 날씨 어때?", "야구 경기 알려줘", "심심하다") 챗봇이 스코프 밖
   요청에 이상하게 반응할 가능성을 원천 차단하기 위한 결정입니다.
4. **자유 질문 채팅** — 위 세 가지 어디에도 안 걸리고, 학사 관련 키워드는 있는 질문일 때만
   Gemini가 `lib/knowledge.ts` 범위 안에서 자유롭게 답변합니다 (안전망). 예: FAQ에는 없는
   "학교 축제 언제야?" 같은 질문 — "학교"라는 키워드가 있어서 여기까지 넘어옵니다.

**1~3번은 LLM을 전혀 호출하지 않는 100% 결정적인(deterministic) 기능이라 항상 정확하고 빠릅니다.**
발표 시연에서는 대부분 이 세 가지로 진행하고, 4번(자유 채팅)은 학사 관련이지만 미리
준비 못한 질문이 나왔을 때를 대비한 안전망이라고 보면 됩니다.

## 1. 처음 실행하기

```bash
npm install
cp .env.local.example .env.local
```

`.env.local` 파일을 열어 `GOOGLE_GENERATIVE_AI_API_KEY`에 발급받은 키를 넣으세요.

키 발급 방법(무료):
1. https://aistudio.google.com/apikey 접속 (구글 계정으로 로그인)
2. "Create API key" 클릭 → 키 복사
3. `.env.local`에 붙여넣기

```bash
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## 2. 가장 먼저 해야 할 일 — 실제 정보 채우기

세 파일에 실제 대림대학교 정보를 채워야 합니다. 코드를 더 건드릴 필요 없이 이 파일들의
텍스트/링크/키워드만 채우면 챗봇이 바로 정확해집니다.

- **`lib/menu.ts`** — 버튼 메뉴에 나오는 카드 내용. `[실제 정보로 교체]` 표시된 `body`
  문구와, 전화번호가 `000-0000-0000`으로 되어 있는 `contacts` 부분을 실제 정보로 바꾸세요.
- **`lib/faq.ts`** — ★ 가장 중요합니다. "수강", "성적 조회" 같은 키워드로 매칭되는
  FAQ 목록입니다. `keywords` 배열에 학생들이 실제로 입력할 만한 다양한 표현을 최대한
  많이 추가하세요(예: "수강신청", "강의 신청", "과목 신청"을 모두 넣어두면 어떤 표현으로
  입력해도 잘 잡힙니다). `answer`도 실제 정보로 채우세요. 항목을 더 추가하고 싶으면
  `FAQ_ITEMS` 배열에 객체를 하나 더 추가하면 됩니다.
- **`lib/knowledge.ts`** — 키워드 FAQ에도 안 걸리는 자유 질문(Gemini)이 참고하는 지식.
  마찬가지로 실제 정보를 채워두면 안전망 역할을 더 잘합니다.
- **`lib/scope.ts`** — ★★ 다루는 주제(장학/등록/수강신청/성적/연락처)가 바뀌거나 추가되면
  반드시 확인하세요. 두 가지만 있습니다.
  - `BLOCKED_MESSAGE` — 학사와 무관한 질문에 보여줄 고정 문구. 문장만 바꾸면 바로 반영됩니다.
  - `IN_SCOPE_KEYWORDS` — "이 단어가 있으면 학사 관련 질문으로 인정한다"는 키워드 목록.
    새 주제를 추가하기로 하면 그 주제를 나타내는 단어를 여기에도 추가해야, 그 주제에 대한
    질문이 (FAQ에 없어도) Gemini 자유 답변까지 도달할 수 있습니다. 반대로 이 목록에 없는
    단어만 있는 질문은 전부 `BLOCKED_MESSAGE`로 막힙니다.

## 3. 답변 흐름이 실제로 어떻게 동작하나요

사용자가 입력창에 텍스트를 입력하면 순서대로 이렇게 처리됩니다.

1. `GET /api/faq?q=입력문장` 호출 → `lib/faq.ts`의 `keywords`와 대조해서 매칭되는
   FAQ가 있는지 찾습니다.
2. 매칭된 게 있으면 → 화면에 후보 질문들을 버튼으로 보여주고, 사용자가 그중 하나를
   선택하면 `GET /api/menu?nodeId=faq-<id>`로 미리 작성된 답변을 그대로 보여줍니다.
   (이 경로는 절대 LLM을 호출하지 않습니다)
3. FAQ 매칭이 하나도 없으면 → 같은 `/api/faq` 응답 안의 `blocked` 필드를 확인합니다.
   `lib/scope.ts`의 `IN_SCOPE_KEYWORDS` 중 하나도 입력에 없으면(날씨/스포츠/잡담 등
   학사와 무관한 질문 전부 포함) `blocked: true`가 내려오고, 화면은 `blockedMessage`
   (고정 문구)만 보여줍니다. **이 경우 `/api/chat`은 아예 호출되지 않습니다.**
4. `blocked`가 `false`일 때만(=학사 관련 키워드는 있는데 FAQ에 없는 질문) →
   `/api/chat`으로 넘어가서 Gemini가 `lib/knowledge.ts` 범위 안에서 자유롭게 답변합니다.

즉 "수강"이라고 입력하면 1번에서 바로 여러 개의 수강 관련 질문 후보가 뜨고, 그중 하나를
클릭하면 즉시(로딩 없이) 정확한 답이 나옵니다. "오늘 날씨 어때?", "야구 경기 알려줘",
"심심하다"처럼 학사와 전혀 무관한 말을 입력하면 3번에서 걸려서 Gemini 호출 없이 고정
문구만 뜹니다.

## 4. 폴더 구조 (팀원2가 다루는 부분)

```
app/
  page.tsx            # 화면 (팀원1이 자유롭게 스타일 바꿔도 되는 참고용 UI)
  api/menu/route.ts   # 버튼 메뉴 + FAQ 답변 API — GET /api/menu?nodeId=xxx
  api/faq/route.ts    # 키워드 FAQ 검색 + 학사 무관 질문 차단 API — GET /api/faq?q=검색어
  api/chat/route.ts   # 자유 질문 채팅 API (안전망) — Gemini 호출
  globals.css         # 스타일
lib/
  menu.ts             # 버튼 메뉴 트리(카드+링크+버튼 구조)
  faq.ts              # ★ 키워드 FAQ 목록 — 가장 자주 손댈 파일
  scope.ts             # ★★ 학사 무관 질문 차단 — 고정 문구 + 화이트리스트 키워드
  knowledge.ts         # 자유 채팅(안전망)용 지식 + 시스템 프롬프트
  links.ts             # 대림대 공식 사이트 링크 모음
```

### API 계약 (팀원1이 UI만 새로 짤 때 참고)

**`GET /api/faq?q=검색어`**

```json
{
  "query": "수강",
  "matches": [{ "id": "course-period", "question": "수강신청 기간이 언제인가요?" }],
  "blocked": false,
  "blockedMessage": null
}
```

학사 관련 키워드가 하나도 없는 질문(날씨, 스포츠, 잡담 등 전부 포함)이면 이렇게
내려옵니다 (이때는 `/api/chat`을 호출하면 안 됩니다).

```json
{
  "query": "야구 경기 알려줘",
  "matches": [],
  "blocked": true,
  "blockedMessage": "저는 대림대학교 학사 안내만 도와드려요. 장학 · 등록 · 수강신청 · 성적 · 교내 연락처 중에서 질문해주세요."
}
```

**`GET /api/menu?nodeId=scholarship`** (또는 `nodeId=faq-course-period`처럼 `faq-` + FAQ id)

```json
{
  "id": "scholarship",
  "intro": "장학금 안내해드릴게요! ...",
  "topLink": { "label": "학부 장학안내 바로가기", "url": "https://..." },
  "cards": [
    { "title": "성적우수장학금", "body": "...", "link": { "label": "상세안내", "url": "https://..." } }
  ],
  "quickReplies": [
    { "label": "교내장학금", "targetId": "scholarship-internal" }
  ]
}
```

권장 UI 흐름: 입력창 제출 → `/api/faq`로 검색 → `matches`가 있으면 버튼 목록으로 보여주고
클릭 시 `nodeId=faq-<id>`로 `/api/menu` 호출해서 답변 카드 표시 → `blocked`가 `true`면
`blockedMessage`만 표시하고 끝(`/api/chat` 호출 금지) → `blocked`가 `false`일 때만
`/api/chat`으로 자유 질문. 팀원1은 이 흐름만 지켜서 원하는 디자인으로 새로 렌더링하면
됩니다.

## 5. 팀 협업 포인트

- 팀원1(UI/발표): `app/page.tsx`, `app/globals.css`에서 화면 디자인을 자유롭게 바꿔도
  됩니다. 위 API 계약만 지키면 완전히 새로운 디자인으로 다시 짜도 로직은 그대로 동작합니다.
- 팀원2(AI/개발): `lib/faq.ts`(키워드+답변) · `lib/menu.ts`(메뉴 구조) · `lib/scope.ts`
  (차단 문구+화이트리스트) · `lib/knowledge.ts`(안전망) 채우기, `app/api/chat/route.ts`에서
  모델 교체(`gemini-2.5-flash` ↔ `gemini-2.5-flash-lite`), 키워드 매칭 품질 테스트.

## 6. 배포 (발표 당일 안정성을 위해 미리 해두는 것을 추천)

가장 빠른 방법은 Vercel입니다.

```bash
npm i -g vercel
vercel
```

배포 후 Vercel 프로젝트 설정(Environment Variables)에 `GOOGLE_GENERATIVE_AI_API_KEY`를
등록하세요. 로컬 인터넷이 불안정할 때를 대비해 배포된 주소를 백업 시연 링크로 준비해두면
좋습니다.

## 7. 자주 발생할 수 있는 문제

- **처음 화면에 인사말이 아예 안 뜸** → `/api/menu`가 500 에러를 낸 경우입니다. 터미널에
  뜨는 에러 로그를 확인하세요. (menu.ts 문법 오류일 가능성이 큽니다)
- **"수강"이라고 입력했는데 후보가 하나도 안 뜸** → `lib/faq.ts`의 해당 항목 `keywords`에
  "수강"을 포함하는 단어가 없는 경우입니다. keywords 배열에 추가하세요.
- **자유 채팅 답변이 "정확한 정보는 문의해 주세요"만 계속 나옴** → `lib/knowledge.ts`가
  아직 placeholder 상태인 경우입니다. 실제 정보로 채워주세요.
- **채팅 API 에러(401/403)** → `.env.local`의 `GOOGLE_GENERATIVE_AI_API_KEY`가 잘못됐거나
  누락된 경우입니다. 키를 넣은 뒤 `npm run dev`를 재시작하세요.
- **Gemini 무료 티어 요청 제한 초과(429)** → 짧은 시간에 요청이 몰리면 발생할 수 있습니다.
  발표 리허설 때 미리 여러 번 테스트해서 제한에 걸리는지 확인해두세요.
